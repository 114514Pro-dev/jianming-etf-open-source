# 简明ETF模拟交易 v1.2.1：当天行情整合五策略

本次把五个创业板优选策略加入“当天行情”页的“参考策略”下拉框。现在同一处共14项：前5项为创业板优选，后9项为原四资产策略。旧策略、账户、历史比较与报告都保留。

## 直接使用

1. 关闭旧版或标题带“隔离验收”的旧窗口；从原快速启动快捷方式重新打开，标题应显示 v1.2.1。
2. 进入“当天行情”，在“参考策略”选择五个新增策略之一。首次打开默认显示这一页和均线突破量能组合；之后记住你选择的参考策略。
3. 输入独立参考本金，点击“更新参考目标”。下方显示创业板ETF159915与现金的目标比例、金额，以及持有、待买入、待卖出或现金等待状态。
4. 点击“查看策略判断依据”，查看参数、信号K线时间、参考持有期及待执行原因。
5. 点击“立即刷新当天报价”或头部“刷新行情”，同时更新四只ETF报价和五策略所需的完整分钟/周线资料。开启当天页的30分钟自动刷新后，也会一起更新。

## 参考目标的口径

- 原九策略仍使用原盘中参考计算；新五策略只用已经结束的真实K线。每次明确显示完整60分钟行情截至时间和信号K线截至时间，周线信号日期可能早于最新分钟行情。
- 新五策略的参考状态从2023-01-03起模拟，用于跟踪持有期、T+1及待执行信号；读取时不建立、推进或改写任何实际账户。
- 上方输入的本金只用于分配参考金额。表里的100%或0%是下一步参考目标；实际可执行份数还需考虑整手、费用、下一根开盘行情与T+1。底部说明会区分目标与尚未成交的参考持仓。
- 周线SKDJ＋TRIX按原固定20个交易日策略跟踪，买入日为第1日，第20日收盘形成期满退出，第21交易日开盘模拟执行；不会把一个旧周线多头状态当作永久持仓。
- 新五策略与原九策略的历史排名分开显示。原9策略更新排名后，新增5项仍保留在下拉框。
- 行情源失败时保留已有数据并标明时间与失败原因；无效本金会清空旧方案，避免误看上次结果。

当前参考配置不是顶部历史账户的实际仓位，也不会自动成交。持续模拟记账仍在“创业板优选 · 5策略 → 创业板模拟账户”中操作。
