简明 ETF · Windows 本机同步工具（只读验收）

1. 安装来自 python.org 的 Windows x64 Python 3.13（包含 Tcl/Tk 与 py 启动器）。
2. 将 ZIP 完整解压到自己的文件夹，再双击 launch.cmd。第一次会安装锁定的依赖。
3. 在 https://8.210.39.161/d0-control 登录网站后，点击「生成配对码」。
4. 把一次性配对码粘贴到工具，点击「连接网站」。网页应变成「已接收到本机工具的连接」。
5. 若要核对券商，只在本机工具输入本人资金账号和交易密码，点击「登录并只读核对」。

工具只向网站发送连接状态和成功/失败，不发送券商账号、密码、会话、余额、持仓或文件。
配对码 5 分钟有效，只能使用一次。每次配对只同步一次核对结果；重试请重新生成配对码。
配对后，工具也会独立接收网站发布的已确认 D0 目标。关闭浏览器不会停止接收；工具必须保持运行，配对到期需重新连接。网站未确认新信号时只会等待。
本工具没有下单、撤单或自动量化能力。网页上显示成功是工具报告的只读结果，不是券商成交回执。
