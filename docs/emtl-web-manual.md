# 东方财富证券网页手动委托（EMTL 0.3.1）

**默认关闭。** 旧部署启用 `ETF_D0_WEB_PREVIEW=1` 仍只会拟单。登录简明 ETF 后，可从侧栏、总览或手机「更多」打开「东方财富证券」（`/d0-control#broker`）。未启用实盘或不在配置的私有入口时，页面仍显示券商卡片与原因，但不会显示证券密码输入框。启用后仅允许选定的单一账户、D0 的四只 ETF、当前 D0 执行日的连续时段内，在有新鲜行情时提交整手限价买卖。**它不是自动跟随 D0，不自动把拟单变成委托，也没有网页撤单功能。**

## 上线前

1. 实盘路径必须用 HTTPS、网站认证及客户端网络授权。可以与公开页面使用同一个 HTTPS 地址，但券商接口只接受同一公网 IP 的本机配对授权，或 `ETF_EMTL_ALLOWED_IPS` 列出的固定客户端 IP。不接受通配符或网段。代理必须保留正确的 Host，并覆盖或清除上游传入的转发头；应用端只信任 `FORWARDED_ALLOW_IPS` 中列出的直接代理 IP，不能保留 `*`。应用端口不能暴露给公网。在非白名单网络验证券商登录与设置均被拒绝。禁止请求体日志、调试网络日志和第三方埋点。本功能不支持共享实例上的多个券商账户。确保仅运行一个应用进程，保持数据目录独占和持续存储。
2. 确认券商授权该账户经 EMTL 的接口登录和交易。EMTL 是非官方库；对真实资金响应的 `Data[0].Kyzj`、`positions` 结构，委托编号 `Wtrq` / `Wtbh`、沪深市场参数和状态字段，仍需在实际部署的券商环境核对。本库公共文档并不保证这些字段；不认识的响应会阻止操作或将提交标记为未知。切勿用生产账户测试未知结构后重复下单。
3. Docker 生产发布可用 `python scripts/release.py --with-emtl --output <目录>` 将锁定版本打进镜像；安装依赖不会打开券商登录或下单。先核对证书、白名单拒绝行为和升级前备份，再开启只读登录。须先在券商官方客户端核对资金与持仓，方可另外启用真实委托。首次委托建议在「设置 · 实盘委托限额」中先调低上限。

```dotenv
ETF_D0_WEB_PREVIEW=1
ETF_WEB_SECURE_COOKIE=1
ETF_WEB_TRUSTED_HOSTS=etf.example.com,127.0.0.1,localhost
ETF_EMTL_ORIGIN=https://etf.example.com
ETF_EMTL_ENROLLMENT_SHA256=填一次性开通码的SHA256（不是真实账号或交易密码）
ETF_EMTL_CONNECTOR_IP=1
# ETF_EMTL_ALLOWED_IPS=固定运维白名单（可选；不需要时留空）
FORWARDED_ALLOW_IPS=填直接反向代理的IP
ETF_EMTL_MAX_ORDER_CNY=800000
ETF_EMTL_MAX_DAY_CNY=5000000
ETF_EMTL_WEB_LIVE=1
ETF_EMTL_ORDERS_ENABLED=0
```

`ETF_EMTL_CONNECTOR_IP=1` 允许在单一操作人的私人站点上用本机工具临时授权，不必手填公网 IP。用同一网络打开网页、点击「开始配对」，再在工具中输入配对码。网站只使用来自已正确配置的 HTTPS 反代的连接来源：浏览器生成配对码和工具认领配对码时必须来自同一公网 IP。临时网络授权只对发起配对的网页会话有效，15 分钟后失效；换网络、退出网站、重新配对或服务重启后须重新配对。如果两端公网 IP 不同，仍可连接收信，但不会获得网页券商访问权限。不要用于多人共用网站口令的站点。固定 IP 白名单仍可单独使用；只用工具授权时不要同时填写固定白名单。验证反代会覆盖外部传来的转发头，不允许使用 `FORWARDED_ALLOW_IPS=*`。

把占位值换成实际配置，放在仅服务管理员可读的服务器配置中。管理员在可信终端运行下面的命令，仅把哈希写入配置，把开通码通过私下渠道交给唯一授权操作人。不要把码写入日志，也不要在环境文件写证券交易密码。已有部署可以继续使用原来的 `ETF_EMTL_ACCOUNT`；首次网页授权不需要该变量。

```sh
python3 -c 'import hashlib,secrets; c=secrets.token_urlsafe(32); print("开通码:",c); print("ETF_EMTL_ENROLLMENT_SHA256="+hashlib.sha256(c.encode()).hexdigest())'
```

部署后，在允许的 HTTPS 地址用「授权并绑定唯一资金账号」填写开通码、资金账号、交易密码，并输入 `同意绑定`。只有券商登录、资金持仓和委托查询成功后才落库。绑定库只保存账号指纹，不保存开通码、账号原文或证券密码。绑定成功后开通码不能再次使用，即使重启也不会换绑；可以移除 `ETF_EMTL_ENROLLMENT_SHA256`。如要更换账号，请登录当前已绑定的券商账号，展开「解绑当前账户」，输入 `确认解绑`。有未结委托、查询失败或存在无法核对的历史委托时会拒绝解绑。解绑不会撤单，不删除委托日志，不重置限额及当日累计额；会立即断开券商连接，使旧拟单与旧开户码失效。网页会仅显示一次新的单次开通码，请先复制并妥善保存，再绑定下一个账号；重启后仍可用至成功绑定。若丢失，请联系管理员在停止服务并备份后，确认 `broker_policy` 无绑定且 `broker_rebind` 有待绑定记录，再以新开通码的 SHA-256 替换 `broker_rebind.code_tag`；不要删除数据库或委托历史。用 `ETF_EMTL_ACCOUNT` 固定的旧部署须先由管理员移除该变量并重启，再对原账号做网页解绑。

上限按此控制台发起的买卖委托总金额累加，不等于券商全渠道总额，不应同时从其他终端向同一账户发单。公网临时演示不能复用这套实盘配置。默认单笔 80 万、单日累计 500 万；用户连接券商后可以把两项限额调整到不高于 500 万元，且单笔不能大于单日。保存的限额优先于环境默认值，重启保留，不清除今日已发送金额。完成只读验收后，可一次性设 `ETF_EMTL_ORDERS_ENABLED=1` 允许用户在网页自助授权委托；它不会直接允许任何会话下单。此后日常开启和停止不需要 SSH。改回 `0` 后重启是管理员强制只读开关。完全关闭功能设 `ETF_EMTL_WEB_LIVE=0` 后重启，已发送到券商的委托不会因此撤销。

## 操作与故障处理

- 登录网站后打开 D0 控制台，在确认证书无误的地址登录券商。每次登录默认只读。密码通过 HTTPS 发送到本应用，不写入数据库、配置或浏览器存储。本站不再为券商连接加固定倒计时，使用 EMTL 的默认登录参数。实际有效期由券商决定，不承诺永不断开；不保存密码自动续登。网站会话撤销、断开、重启或券商查询失败时停止。配对网络授权仍独立有效 15 分钟。
- 在实盘权限中输入 `开启实盘` 后仍不能发单；再输入当前绑定账号、密码和 `允许真实委托`，通过一次新的券商登录核对后，当前网页会话获得手动下单权限。这两步都不会发单。点击「停止实盘委托」、退出网站、断开券商连接、到期或重启会清除权限和未提交拟单，不会撤销已在券商处的委托。
- 交易时先选 ETF、买卖方向、份额与限价，点击「核对真实委托」；再输入 `确认实盘` 并在 30 秒内提交。服务器重查实际可用资金或可卖份额、委托和市场状态，单笔及单日限额由服务器强制执行。限制价格在当前 D0 报价允许范围内。收到编号表示获得券商回执，**不表示成交**。
- 如果结果不明、页面断开或收到 5xx，**先到东方财富证券官方终端核对当天委托和成交，不要重发**。提交之前会在 `SIMPLE_ETF_HOME/web/emtl-manual.sqlite3` 持久化意图。进程崩溃、无清楚回执或上一笔未达明确终态时会阻止新的单。跨日未核对记录也会阻断。保留日志与数据库，管理员先核对券商记录再处理，不要直接删除日志当作解锁。日限额统计已登记的发送意图（包含未知结果），不会因重启重置。
- 收盘后仍可连接账户，但拟单与真实发单会显示「非连续交易时段」。进入盘中后若仍不能算单，检查是否开启新鲜行情采集、信号是否已经确认及日历范围。本版不会用历史或收盘后的报价代替盘中报价。

## D0 / F0 自动委托

- 只支持原 D0 和 F0 主策略；F0 必须由同一部署里的独立 F0 服务提供已确认输入，没有源时报错，不回退 D0，不支持 511020 等变体。原策略计算不变；执行共用交易时间、报价新鲜度、限价、手数及账本约束。
- 初始安装保持 `ETF_EMTL_AUTO_ENABLED=0`。先用官方客户端核实真实的券商**总资产字段**、订单回执、成交数量 `Cjsl`、明确终态和可用资金的实际语义；不要猜测字段。配置 `ETF_EMTL_AUTO_EQUITY_FIELD` 后可以只预演。验证并批准真实验收后，管理员才可一次性设置 `ETF_EMTL_AUTO_ENABLED=1`；启用能力仍不会启动任务。`ETF_EMTL_AUTO_MAX_CYCLE_CNY` 默认为 5000 元，同一网站单笔、累计限额仍生效。此后日常启停和策略选择都在网页。
- 连接券商后选 D0 或 F0，预演只读取券商和行情；确认显示的份额、限价、保留现金和预算，开启真实委托后，须另输 `确认自动委托`。预演有效 60 秒，执行最多 15 分钟，且受网站授权、当日已确认信号、配对和交易时段约束；不会自动续期或跨日恢复。更换策略必须停止旧运行并重新预演。当天一旦有自动发单意图，切换不能再次启动自动周期。
- 使用核实的券商总资产冻结目标。账户含其他证券、非整手或超出自动限额时拒绝执行。先卖后买，订单逐笔执行，核对唯一回执、整笔成交数量、持仓、可用资金和保留现金；价格不得突破预演披露的限价。部分成交、券商结果不明、持仓变化、授权或行情失效均停止发出下一笔，不自动重发／撤单。自动运行时禁止同时手动发单、调整限额或解绑；「停止自动委托」不撤销已提交订单。

代码和交互测试使用合成券商/合成数据，未登录或向东财发送真实委托；真实映射验收和部署分别确认。
